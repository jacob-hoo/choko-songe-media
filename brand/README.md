## 바꾸는 곳 (계정 로그인 필요, 대장님)
- 인스타그램: 프로필 편집 → 사진 변경 / 이름 / 사용자 이름. 쓰레드는 인스타 사용자 이름을 따라간다.
- 쓰레드: 프로필 편집 → 사진 / 이름(인스타와 같은 값).
- 틱톡: 프로필 편집 → 사진 / 이름 / 사용자 이름(30일에 한 번만 바꿀 수 있음).
- 유튜브(스튜디오): 맞춤설정 → 브랜딩(사진·배너) / 기본 정보(이름·핸들). 핸들은 14일에 2번까지.
- 사용자 이름이 이미 쓰이면 예비 계정명으로.
