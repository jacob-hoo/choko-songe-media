# 초코송이 라운지 (AI 음악 롱폼 + 쇼츠)

초코송이 채널의 새 부업 방향은 2026-10-21 대장님이 확정했다.
- 유튜브 1시간 플레이리스트와 쇼츠
- 보조: 크몽 생일축하곡

## 흐름

```
[대장님] Suno Premier에서 곡 생성·선별 → 내려받기
   ↓
lounge.py ingest <장면> <폴더>   곡 등록 (tracks.csv)
lounge.py render <장면>          1시간 롱폼 + 제목·설명(트랙리스트=챕터)·썸네일
lounge.py shorts <장면> --n 7    곡마다 25초 세로 쇼츠
   ↓
Metricool 예약 (유튜브 롱폼 주 2편, 쇼츠 매일)
```

## 명령

| 명령 | 하는 일 |
|---|---|
| `prompts <장면>` | Suno에 넣을 스타일과 설정 출력 |
| `ingest <장면> <폴더>` | 폴더의 mp3·wav를 `audio/<장면>/`으로 복사하고 길이를 재서 등록 |
| `image <장면>` | 장면 그림이 없으면 임시 그림 생성 (`art/<장면>.png`, 1920×1080) |
| `render <장면> [--max-minutes 60]` | 곡 사이 3초 크로스페이드, 화면 하단에 지금 곡 제목, 2fps 정지화면 렌더링 (1시간에 약 8분) |
| `shorts <장면> [--n 7]` | 곡의 35% 지점부터 25초, 앞뒤 페이드 |
| `test-tracks <장면>` | 자체 합성 시험곡으로 점검. **게시 금지** |

실행은 `tools/.venv/bin/python tools/lounge/lounge.py ...`로 한다.

## 규칙
- 장면은 `scenes.json`에 있는 10개다. 같은 장면을 연속으로 쓰지 않는다. 같은 틀을 반복하면 유튜브 '진정성 없는 콘텐츠'로 판정되어 채널 전체 수익이 정지될 수 있다.
- 설명에는 AI 작곡 사용 고지(`AI_NOTE`)가 자동으로 들어간다. 유튜브 예약 때 `isAiGeneratedContent`를 true로 둔다.
- 곡은 상업 이용이 허용된 **Suno 유료 플랜**에서 만든 것만 쓴다.
  - Rythmix 곡은 약관을 확인할 때까지 쓰지 않는다.
  - 음저협 등록은 하지 않는다. AI 사용 곡은 보류된다.
- 장면 그림은 지금 임시 그림이다. 캐릭터시트가 확정되면 `art/<장면>.png`를 교체한다(directing-choco-songi-clips 참고).
- `audio/`, `out/`, `test_audio/`는 저장소에 올리지 않는다. 롱폼 mp4는 용량이 커서 GitHub raw 주소를 쓸 수 없다. 업로드 방식은 2주차에 정한다.
