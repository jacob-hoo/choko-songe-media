# 쿠팡파트너스 + 1인기업 채널 전략 (2026-10-20)

## 0. 결론 요약 (2026-10-20 수정: 기존 매일 게시 계정 기반)

- **새 채널을 만들지 않고, 매일 올리는 계정에 상품 슬롯을 붙인다.**
  - 봄날 수첩(70대 부모님, 하루 3편)에는 효도템을, 엄마는 늦깎이 대학생(40대 주부, 하루 3편)에는 살림템·공부템을 하루 1편 붙인다.
  - 이미 올린 정보 영상과 이어지는 상품만 고른다. 예: 낙상 예방 영상 → 미끄럼 방지 매트.
- **쿠팡 영상은 인스타그램 중심으로 올린다.**
  - 인스타에서는 프로필 인포크링크와 댓글 키워드 자동 DM이 팔로워 0명부터 작동한다.
  - 유튜브 쇼츠 설명란 링크는 클릭되지 않고, 이미 업로드 한도 오류가 나고 있다. 그래서 쿠팡 영상은 유튜브에 올리지 않는다.
- **1인기업 이야기 채널**은 원래 제이콥(mrjacobhoo)이 맞다. 다만 GPT 담당이라 자동 게시 대상에서 뺐다. 어디서 할지는 대장님이 결정한다.
- **자동화 원칙: 95% 자동, 5% 사람.**
  - 사람은 상품 링크 생성, `my_take` 한 줄, 승인 1클릭만 한다.
  - 유튜브 YPP(2025.7)와 인스타그램(2026.4)이 대량·비독창 콘텐츠를 막기 때문에 이 5%를 남긴다.
- **돈은 광고가 아니라 커미션과 자체 상품에서 번다.** 쇼츠 RPM(조회 1천 회당 수익)은 $0.05~0.3으로 낮다.
- 실행 절차는 `쿠팡파트너스_실행.md`, 매일 절차는 making-coupang-shorts 스킬을 따른다.

## 2. 반드시 지킬 규칙

1. **대가성 문구를 빠짐없이 넣는다.** 문구 누락은 쿠팡파트너스 계정 정지 사유 1위다.
   - 영상: 첫 화면에 오버레이로 표시한다.
   - 캡션: 첫 줄에 넣는다.
   - 인스타: 이미지 안에도 넣는다.
   - 표준 문구: "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
   - 파이프라인이 자동으로 넣고, 빠진 콘텐츠는 게시를 막는다.
2. **비공식 단축 URL, 본인 구매, 미등록 채널 홍보, 금지 커뮤니티 홍보는 하지 않는다.** 가입할 때 채널 A·B를 모두 등록한다.
3. **쿠팡 페이지를 스크래핑하지 않는다.**
   - 최종승인 전에는 상품을 사람이 고르고 링크를 직접 생성해 CSV로 넣는다.
   - Open API는 누적 판매 15만 원을 넘겨 최종승인을 받은 뒤에 켠다.
4. **쇼츠 설명란 링크는 클릭이 되지 않는다.** 그래서 프로필 링크(인포크 링크 등)와 고정 댓글 "프로필 링크 n번"으로 안내한다.
   - YPP 가입 후에는 YouTube 쇼핑 제휴(쿠팡 연동)를 신청한다.
5. **AI 음성·이미지를 실사처럼 보이게 쓰면 AI 라벨을 켠다.**

※ 쿠팡파트너스 약관 원문은 조사 중 접근이 막혀 확인하지 못했다. 가입할 때 약관과 공지를 직접 한 번 읽어야 한다.

## 4. 월 300만 원 가정 (추정치)

- **채널 A 커미션**
  - 계산: 월 매출 3,000만 원 × 3% = 90만 원.
  - 필요 조건: 클릭 약 3만 회 (전환율 3%, 객단가 약 3.3만 원 가정). 쇼츠 조회수가 클릭으로 이어지는 비율을 0.5%로 보면 월 조회수 약 600만 회가 필요하다.
  - 평가: 혼자서는 빡빡한 목표다. 그래서 채널을 여러 개로 복제하는 단계 4가 필요하다.
- **채널 B 디지털 상품**
  - 계산: 키트 59,000원 × 월 35건 = 약 200만 원.
  - 평가: 이쪽이 300만 원 목표의 본체다. 해외 1인기업 사례에서도 매출 대부분이 디지털 상품이었다.
- **합계:** 약 290만 원 + YouTube 쇼핑·광고 수익 소액.
