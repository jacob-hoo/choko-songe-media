# 훅 라이브러리

- 대본 생성(script_gen.py)이 매번 이 파일을 읽는다.
- 주간 최적화(optimizing-shorts-performance 스킬)가 성과를 반영해 고친다.
- 처음 값은 미국·일본 사례에서 가져온 가설이다. 우리 성과가 쌓이면 표 맨 오른쪽 '근거' 칸에 수치를 적어 바꿔 나간다.

## 잘 된 유형 (우선 사용)

| 유형 | 형식 | 예시 | 근거 |
|---|---|---|---|
| 연계 정보 되짚기 | 그 채널이 이미 올린 정보 영상의 결론에서 시작해, 실천 도구로 넘어간다 | "욕실 매트, 어떤 걸 깔까요" | 가설: 일본 저장형 계정의 '나중에 다시 볼 이유'. 정보가 먼저라 광고 거부감이 적다 |
| 고르는 기준 3가지 | 상품보다 고르는 기준을 먼저 보여준다 | "센서등 고를 때 3가지만 봐요" | 가설: Amazon Influencer 상위 리뷰 형식, 저장률이 높은 리스트형 |
| 써보고 아쉬운 점 | 단점 한 가지를 먼저 말한다 | "이 타이머, 이건 아쉬워요" | 가설: TikTok Shop에서 신뢰가 전환율을 만든다는 관찰 |
| 부모님 집 점검 | 점검 목록 형식으로 묻는다 (봄날 수첩 전용) | "부모님 댁 욕실, 이것 있나요" | 가설: 자녀 시청자가 저장하고 공유함 |
| 숫자 하나 | 가격, 시간, 개수를 화면 가운데 크게 보여준다 | "1만 5천 원으로 밤길 밝히기" | 가설: Amazon 사례의 가격 앵커 |

## 시험 중 (국내 쇼핑쇼츠 강의 영상 상위 5편, 2026-10-20 분석. 주 2편까지)

| 유형 | 형식 | 예시 | 출처 |
|---|---|---|---|
| 금지형 | "더 이상 ○○하지 마세요" | 봄날: "무릎 굽혀 걸레질, 이제 그만하셔도 돼요" / 엄마: "시험 기간 형광펜 다섯 개, 이제 그만" | 이웃집사장 |
| 원인 반전형 | "○○가 안 되는 이유, △△ 때문이에요". △△는 실제 리뷰 불만에서 가져온다 | "약 봉투가 헷갈리는 이유, 글씨 크기 때문이에요" | 홍아린 AI (Claude 자동화) |
| 리뷰 숫자형 | "후기 ○천 개, 가장 많이 나온 말은 '○○'". 실제 리뷰 수와 문구만 쓴다 | "후기 1만 개, 제일 많이 나온 말은 '안 미끄러져요'" | 홍아린 AI |
| 질문 공감형 | "○○ 해보신 적 있으시죠" | "리모컨 버튼이 작아 엉뚱한 채널 누르신 적 있으시죠" | 이웃집사장 |
| 비밀 하나형 | 마지막 하나를 숨기고 댓글 키워드로 연다 | "냄비 탄 자국, 마지막 이것 하나로 지워져요. 궁금하면 댓글 '냄비'" | 머니로드 (지어낸 체험 부분은 제외) |
| 대상 호명형 | 시청자를 바로 부른다 | "70대 부모님 댁에 하나씩 두면 좋은 것" / "40대에 공부 다시 시작한 분들, 이건 챙기세요" | 공통 |
| 가격 비교형 | "1만 원대 vs 3만 원대, 차이는 딱 하나". 사양만 비교하고 사용 후기는 쓰지 않는다 | | 이웃집사장 (저가형과 평점 우수형 2종 등록) |
| 이것 하나 전후형 | 전후 차이가 화면에 보이는 상품만 쓴다 | "책상 조명 하나로 밤 공부 눈부심이 줄어요" | 온도스토리 |
| [가상 상황] 장면형 | 장면을 상상하게 하고 가상 상황을 표기한다 | "[가상 상황] 손주 오는 날, 현관 미끄럼이 걱정된다면" | 머니로드·너굴 (지어낸 체험을 가상 상황 표기로 바꿈) |

## 피할 유형

| 유형 | 이유 |
|---|---|
| "이거 안 사면 손해" 식 압박 | 공정위 과장광고 소지가 있고, 시니어 대상 채널의 신뢰를 깎는다 |
| 상품 이름으로 시작 | 광고로 인식되어 넘김률이 높다 (가설) |
| 매번 같은 첫 문장 | 유튜브 YPP의 '진정성 없는 콘텐츠' 판정 위험이 커진다 |
| "친구가 20kg 뺐다", "샀는데 이것만 써요" 같은 지어낸 체험 | 공정위 추천·보증 지침상 기만광고다 (강의 영상 4편에서 쓰지만 따라 하지 않는다) |
| 공포 소구 ("방치하면 끝납니다") | 시니어 대상이라 특히 위험하고, 건기식이면 건강기능식품법 위반 소지가 있다 |
| 시댁·고부 갈등 썰 + 무관한 상품 | 클릭은 늘어도 두 채널 톤과 맞지 않고 신뢰를 깎는다 |

## 성과 기록

성과 지표는 조회수보다 댓글(키워드) 수, DM 발송 수, 쿠팡 클릭을 우선 본다. 강의 영상 5편이 공통으로 꼽은 지표다.
